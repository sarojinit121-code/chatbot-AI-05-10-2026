Ollama Local LLM Setup Guide

LocalLens connects to Ollama running privately on your laptop. General subject answers use a model running locally on your computer. No external API keys or cloud AI service are required.

1

Download & Install Ollama

If you don't have Ollama yet, download it from ollama.com.

2

Pull the Llama 3.2 Model

Open your terminal (PowerShell or Command Prompt) and run:

ollama pull llama3.2:3b
3

Start Ollama Engine

Start the local server daemon:

ollama serve
🛡️ Built-in Offline Support: Current time is read from your computer clock, and supported South India tourism questions use the local SQLite knowledge base. General subject answers require Ollama to be running.
